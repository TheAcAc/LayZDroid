# LayZDroid 0.1.0 Preview 2

- Fix startup when another custom emulator already uses the ADB connection.
- Fix Windows process identity detection for existing ADB servers.
- Import APK and Open KaW start the selected instance when needed.
- Add Delete selected, with confirmation and protection for running instances.

Download LayZDroid.exe. Existing instances and settings are kept. The separate [KaW download](https://github.com/TheAcAc/LayZDroid/releases/download/v0.1.0-preview.1/KaW-362-APKs.zip) is unchanged: Extract All, then use Import APK to select all three APK files together.

Verified on the local Windows machine: Android boot, KaW APK installation and KaW launch. User testing also confirmed that KaW opens successfully. No signed-in battle automation or weak-PC performance claim is implied by this check.
