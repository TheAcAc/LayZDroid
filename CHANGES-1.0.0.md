# LayZDroid 1.0.0

- Standard 900 x 1600 portrait display at 240 DPI for LayZ integration.
- Existing instances adopt the standard display on startup while keeping their games and accounts.
- Verified Android display settings and bounded startup internet recovery.
- Resource checks, separate instance storage, APK import and native launcher controls.

Windows x64 standalone executable. Android runtime setup is separate. Low-RAM performance and unattended recovery remain experimental.
